# Projet-FilRouge-DRINGOTJoey

### Présentation du projet :

Ce projet consiste à réaliser un site web pour présenter le portfolio d'une photographe fictive, Solène Avril.

Le site permet de découvrir une présentation de la photographe ainsi qu'une galerie de photographies.

### Technologies utilisées : 

* HTML : structure des différentes parties du site.
* CSS : mise en forme et adaptation aux différentes tailles d'écran.
* Google Fonts : intégration des polices Montserrat et Yeseva One.
* Font Awesome : utilisation des icônes des réseaux sociaux.

### Fonctionnalités : 

* Présentation de la photographe.
* Galerie composée de plusieurs photographies.
* Affichage des différentes catégories (Nature, Portrait, Art, Urbain et Animaux).
* Effet de zoom sur les photographies au passage de la souris.
* Ouverture de chaque photographie dans un nouvel onglet lorsqu'on clique dessus.
* Liens vers les réseaux sociaux.
* Affichage adapté pour ordinateur, tablette et mobile.

Remarque : Les catégories du menu sont uniquement présentes à titre visuel. Elles ne permettent pas de filtrer les photographies car aucun JavaScript n'a été utilisé dans ce projet.

### Organisation du projet :

* index.html : structure principale du site.
* style.css : mise en forme et design du site.
* images/ : dossier contenant les photographies utilisées.

## Validation du code :

Le code HTML et CSS a été vérifié à l'aide des deux validateurs W3C :

* Validateur HTML : aucune erreur détectée (1 avertissement).
* Validateur CSS : aucune erreur détectée.
